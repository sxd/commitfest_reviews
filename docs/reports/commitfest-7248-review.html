Overview

The patch rewords one block comment preceding the statement LogicalDecodingCtl->xlog_logical_info = true; inside EnableLogicalDecoding(void) in src/backend/replication/logical/logicalctl.c (lines 356–360). The original wording "All process starts after this point" was ungrammatical (singular noun "process" with the verb "starts", or a missing participle); the new wording "All processes starting after this point" is grammatically correct. The comment is rewrapped to fit the column limit. No executable code is changed: all three added lines and all three removed lines lie entirely inside the /* ... */ block comment. The adjacent executable statement LogicalDecodingCtl->xlog_logical_info = true; (line 361) is byte-for-byte identical to the base.

The comment accurately describes the surrounding code: it sets the shared-memory flag so that processes starting afterward include logical-decoding information in WAL. The subsequent EmitProcSignalBarrier(PROCSIGNAL_BARRIER_UPDATE_XLOG_LOGICAL_INFO) + WaitForProcSignalBarrier (lines 370–371) handles already-running processes, while the comment correctly scopes itself to processes starting after this point, which learn the flag via startup initialization. The corrected wording improves readability without any semantic shift.
