Patch summary

Tom Lane's patch replaces three per-GUC show_hook functions (show_data_directory_mode, show_log_file_mode, show_unix_socket_permissions) with a single GUC_SHOW_IN_OCTAL = 0x010000 flag. The flag is honored in three display/validation paths so that pg_settings min_val/max_val/boot_val/reset_val are displayed in octal alongside the current setting value, eliminating a long-standing inconsistency where the current value was octal but the range columns were decimal.
