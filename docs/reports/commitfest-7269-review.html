CommitFest 7269 Review: postgres_fdw WITH TIES Pushdown

Summary

Verdict: ready-for-committer

The patch enables pushdown of FETCH FIRST .. WITH TIES to remote PostgreSQL servers in postgres_fdw when a cached connection already exists for the session and reports version >= 13. It adds GetCachedConnectionVersion() which consults the connection cache without performing network I/O, modifies add_foreign_final_paths() to check the cached version before allowing pushdown, and updates appendLimitClause() to emit the SQL-standard FETCH FIRST ... ROWS WITH TIES syntax with parenthesized values to work around the c_expr grammar restriction.

The approach is safe, well-designed, and addresses a known limitation documented in commit 2b461efc519 (which disabled WITH TIES pushdown due to bug #18467). The design avoids plan-time network I/O by only using already-cached connection versions.
