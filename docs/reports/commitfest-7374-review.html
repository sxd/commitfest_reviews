CommitFest 7374 Review: psql tab-completion fix for GRANT/REVOKE CREATE

Summary

Patch: [PATCH] psql: avoid CREATE command completion after GRANT/REVOKE CREATE Author: Haruna Miwa (miwa@sraoss.co.jp) Date: 2026-10-01 Thread-ID: OSOP286MB78539E88C47403451BFFF140F18A2@OSOP286MB7853.JPNP286.PROD.OUTLOOK.COM

The patch adds an exclusion condition to the generic CREATE tab-completion rule in src/bin/psql/tab-complete.in.c so that GRANT CREATE and REVOKE CREATE (no longer trigger the create_command_generator, which offers irrelevant object types like ACCESS METHOD, AGGREGATE, DATABASE, etc. Instead, the privilege completion path fires and correctly offers ON.

Verdict: ready-for-committer (test follow-up required)

The implementation is correct, minimal, and well-scoped. No correctness, security, performance, or maintainability issues were found. One test-gap finding (COV-1, MAJOR, class=tests) requires a follow-up test patch to guard the new exclusion branch. The proposed test patch has been validated with a two-run gate (passes on patched code, fails on unpatched code).

Location: src/bin/psql/tab-complete.in.c:2189 Severity: MAJOR Class: tests Verification status: verified (by coverage)

Mechanism: The patch adds !TailMatches("GRANT|REVOKE", "CREATE") as a new AND condition to the CREATE completion rule at line 2189. Fresh-epoch gcov branch coverage (measured at HEAD with only the implementation patch applied) shows:

  • Line 2189-2191: executed 1 time (by the existing CREATE TY\t test)
  • Branch 1 (fallthrough, condition true → enters create body): taken 100%
  • Branch 2 (condition false → exclusion triggers): taken 0%

The GRANT/REVOKE CREATE exclusion path is never exercised by any existing test. The TAP test 010_tab_completion.pl does not test GRANT or REVOKE completions at all.

Failure risk: Without a test, a future refactor could remove the exclusion and reintroduce irrelevant create_command_generator suggestions after GRANT CREATE / REVOKE CREATE with no test failure.

Repair: Add two check_completion calls to src/bin/psql/t/010_tab_completion.pl verifying that GRANT CREATE\t and REVOKE CREATE\t produce qr/ON / (the privilege completion path) instead of the create_command_generator object list.
