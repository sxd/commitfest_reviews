Goal

pg_upgrade uses pg_dump --schema-only --binary-upgrade, which strips extension config table data. In the new cluster, binary_upgrade_create_empty_extension() creates extensions without populating config tables, so any CREATE TABLE requiring validation against that data (e.g. PostGIS spatial_ref_sys SRID validation) fails. The patch adds DO_EXTENSION_DATA that emits config table COPY data in SECTION_PRE_DATA during --binary-upgrade only, restoring it before user DDL.
