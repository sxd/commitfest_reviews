Patch summary

Adds a new public libpq API PQpassfileLookup(hostname, port, dbname, username, passfile) exposing the existing static passwordFromFile() pgpass lookup so applications connecting through an intermediary (e.g. local SSH tunnel) can look up the password under the real server's host/port and then feed it to PQconnectdb as the password parameter. NULL/empty hostname→localhost (incl. default socket dir), NULL/empty port→DEF_PGPORT_STR, NULL/empty dbname or username→no password. NULL/empty passfile→PGPASSFILE env or the the default .pgpass file file location. Returns malloc'd string (free with PQfreemem) or NULL. Adds LIBPQ_HAS_PASSFILE_LOOKUP feature macro, export PQpassfileLookup 212, SGML docs, --passfile mode in libpq_testclient, and TAP test t/007_passfile.pl (13 subtests).

Per-finding detail

F-001

— MINOR correctness — swallowed OOM errmsg

PQpassfileLookup passes &errmsg to passwordFromFile but never inspects it. On OOM, passwordFromFile sets *errmsg="out of memory" (lines 8086, 8127) and returns NULL; the public API returns NULL silently. Repair: capture return, fprintf(stderr, "%s\n", errmsg) on non-NULL errmsg; add doc note. Patch SHA256: d0a57deeb....

F-002

— NIT maintainability — blank-line style drift

Two blank lines between passwordFromFile/PQpassfileLookup and PQpassfileLookup/pgpassfileWarning; surrounding code uses one. Repair: collapse to single blank lines (part of combined patch).

F-003

— NIT tests — implicit-only default-port coverage

NULL/empty port→DEF_PGPORT_STR only tested against * wildcard, not a literal default-port entry. Repair: read DEF_PGPORT_STR from pg_config.h, add literal localhost:5432:defportdb:defuser:defportpw entry, add two assertions. Patch SHA256: 499c841be....

S2 — MINOR security — credential residue

Returned password is malloc'd by strdup; PQfreemem is bare free() with no zeroing. Internal path uses explicit_bzero before free. Repair: add SGML note recommending explicit_bzero before PQfreemem. Part of combined patch.

S3 — NIT security — refuted (accepted by design)

Silent credential enumeration without a connection is the intended feature, guarded by the same file-permission checks (0600, plain-file). No fix required.

COV-1

— MINOR tests — home-directory fallback untested

The new public API documents default home-directory password file resolution, but the TAP suite never exercises it. 4 lines (8190, 8192-8194) and 5 branches uncovered. Repair: platform-guarded TAP block with controllable $HOME. Patch SHA256: 327daba51....
