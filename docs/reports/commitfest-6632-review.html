B1 — BLOCKER, correctness — compile error in test_ext_node_read

  • Location: src/test/modules/test_extensible/test_extensible.c:77
  • Mechanism: test_ext_node_read is declared with signature

Inside, pg_strtok(&length) is called with 1 arg, but the current signature is pg_strtok(ReadNodeContext *ctx, int *length) (src/include/nodes/readfuncs.h:37). Core's _readExtensibleNode calls methods->nodeRead(ctx, local_node) (src/backend/nodes/readfuncs.c:565). This is a hard compile error from function-pointer type mismatch; the module cannot build.

  • Verification: verified (static-check). Independent header grep confirms the

signatures. A gcc -c type probe reproduces 3 compile errors; the repair probe compiles cleanly with -Wall -Werror.

  • Repair: Change signature to `test_ext_node_read(ReadNodeContext *ctx,

ExtensibleNode *node), thread ctx into both pg_strtok calls, and replace atoi(token) with pg_strtoint32(tok)` (also resolves n-atoi).

  • Patch SHA-256: 788f62dbddc669159a32de7e1d9b7b266d7aa8bde62220b12874ee6ff24a70d7

M1 — MAJOR, tests — nodeOut/nodeRead/nodeCopy/nodeEqual untested

  • Location: src/test/modules/test_extensible/sql/test_extensible.sql
  • Mechanism: The four ExtensibleNodeMethods callbacks nodeOut, nodeRead,

nodeCopy, nodeEqual are registered but never exercised by any SQL test step. The SQL only runs EXPLAIN (COSTS OFF) + SELECT. nodeOut is reachable only via nodeToString (outfuncs.c:496) and nodeRead only via stringToNode/parseNodeString (readfuncs.c:569), neither triggered here. Half the ExtensibleNodeMethods surface is untested despite the module's stated purpose.

  • Verification: verified (static-check). EXPLAIN (SERIALIZE) does NOT serialize

the plan tree (only result tuples); the plan-tree nodeToString path is parallel query (execParallel.c:152,233). The repair uses nodeToString+stringToNode directly via a SQL-callable C function.

  • Repair: Add test_roundtrip_extensible_node(int) C function that builds a

TestExtNode, serializes via nodeToString, reparses via stringToNode, copies via test_ext_node_copy, compares via test_ext_node_equal, and returns the reparsed repeat_count. Add the CREATE FUNCTION declaration and two SELECT test steps. (Requires B1 fix.)

  • Patch SHA-256: 89b7dfaacc0464a2e58ca460b5d7d84706db6f3cf2f57548b96fb48640e66203

(combined B1+M1)
