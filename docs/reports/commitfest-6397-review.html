Patch summary

examine_variable() strips RelabelType nodes before statistics lookup. The old code did while (IsA(basenode, RelabelType)) basenode = arg; unconditionally, discarding all relabels including collation-changing ones — conflating stats for GROUP BY a COLLATE C and GROUP BY a COLLATE case_insensitive. The patch replaces this in two places with collation-aware logic: walk nested relabels, and if the deepest expr's collation equals the relabel's resultcollid, strip all relabels; otherwise rebuild a single RelabelType preserving the outermost type/typmod/resultcollid/format/location wrapping the deepest expr. Added tests verify selectivity estimates for extended statistics with collations.

H2 — MAJOR (correctness) — verified

Location: src/backend/utils/adt/selfuncs.c:5828

Mechanism: The expressional-index matching loop at line 5828 retained the old naive single-level RelabelType strip (if (indexkey && IsA(indexkey, RelabelType)) indexkey = (Node *)((RelabelType *)indexkey)->arg;) while the query-side basenode became collation-aware via the new top-of-function normalization. The two sides of the subsequent equal(node, indexkey) comparison are now normalized asymmetrically: the query side preserves a collation-carrying RelabelType, the index side strips all RelabelTypes. This produces a false miss when the query collation matches the index (index stats not applied; estimate 25 vs actual 192 in the repro) and a false match when the query collation differs (default-collation query consumes a case_insensitive index's pg_statistic row, applying wrong-collation MCV frequencies).

Failure: Wrong selectivity estimates for expressional indexes built on COLLATE expressions: matching-collation queries fail to use index expression statistics (estimate 25 vs actual 192) and mismatched-collation queries wrongly consume the index's stats (estimate 192 from case_insensitive stats for a default-collation query). Reproduced via EXPLAIN with a temp ICU cluster: CREATE INDEX t1_low_ci ON t1 ((lower(a) COLLATE case_insensitive)); three WHERE-clause variants showed the asymmetry in debug elog of equal(node, indexkey).

Verification: live-repro — Disposable scratch ICU cluster (initdb with icu provider) with the cassert+debug+coverage build at the frozen staged tree. Three queries with collation match/default/C were run through EXPLAIN with a temporary elog(LOG) instrumenting equal(node,indexkey) at the index path. Pre-repair: matching-collation estimated 25 (no stats, false miss); default-collation estimated 192 (false match consuming case_insensitive index stats). Post-repair (strip_relabel_for_stats on indexkey): matching collation estimates 192 (stats applied), mismatches estimate 25 (no stats). The defect pass_on_new=false (present on the patched tree).

Repair instruction:

  • Files: src/backend/utils/adt/selfuncs.c, src/test/regress/sql/collate.icu.utf8.sql, src/test/regress/expected/collate.icu.utf8.out

Suggested code example (provided, illustrative):

/* helper replaces both duplicated blocks and the index path */
static Node *
strip_relabel_for_stats(Node *node, Oid targetcollid)
{
    RelabelType *relabel;
    Expr       *expr;
    if (IsA(node, RelabelType))
    {
        relabel = castNode(RelabelType, node);
        expr = (Expr *) relabel;
        while (expr && IsA(expr, RelabelType))
            expr = ((RelabelType *) expr)->arg;
    }
    else
    {
        relabel = NULL;
        expr = (Expr *) node;
    }
    if (exprCollation((Node *) expr) == targetcollid)
        return (Node *) expr;
    {
        RelabelType *newrelabel = makeNode(RelabelType);
        newrelabel->arg = (Expr *) expr;
        if (relabel)
        {
            newrelabel->resulttype = relabel->resulttype;
            newrelabel->resulttypmod = relabel->resulttypmod;
            newrelabel->relabelformat = relabel->relabelformat;
            newrelabel->location = relabel->location;
        }
        else
        {
            newrelabel->resulttype = exprType((Node *) expr);
            newrelabel->resulttypmod = exprTypmod((Node *) expr);
            newrelabel->relabelformat = COERCE_IMPLICIT_CAST;
            newrelabel->location = -1;
        }
        newrelabel->resultcollid = targetcollid;
        return (Node *) newrelabel;
    }
}
